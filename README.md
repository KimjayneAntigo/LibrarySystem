Library Management System

Overview
A web-based Library Management System developed using PHP, MySQL, Bootstrap, and XAMPP.

Features
- User Authentication
- Dashboard
- Book Inventory
- Member Management
- Borrow & Return
- Fine Management
- Reports
- Leaderboard
- Gamification (Badges & Points)

Technologies Used
- PHP
- MySQL
- Bootstrap 5
- XAMPP
- HTML/CSS
- JavaScript
Installation
1. Install XAMPP.
2. Place the project inside `htdocs`.
3. Import `library_db.sql` into phpMyAdmin.
4. Start Apache and MySQL.
5. Visit `http://localhost/LibrarySystem`.
